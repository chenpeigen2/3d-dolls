## 仍需补齐的参考

当前只有一张正面照片，以下视角缺失，模型中的对应结构属于依据常识与材质逻辑的合理推断：

- 左右侧面（用于校准头部厚度、嘴部翻边、手臂与裤子的前后关系）
- 背面（背带在背后的走法、裤子后片结构）
- 眼部特写（眼眶抽褶的数量、密度与走向）
- 顶部连接结构（皮绳打结方式、金属环与标签的连接细节）

补齐自有实拍照片后，应优先修正这些部分，并同步更新 `scripts/blender/build_frog.py` 中的控制点参数。
