# 参考图板与来源记录

本目录用于收集建模所需的参考照片。**每一张参考图都必须登记来源、授权与用途**，
登记规则见项目根目录的 `ASSET_SOURCES.md`。

> 目录下的图片默认只作内部结构参考；只有登记了明确授权的素材才允许进入公开产物。

## 仍需补齐的参考

当前原图只有一张正面照片；卖家图补充了俯拍与材质细节，但以下视角仍没有可靠参考，
模型中的对应结构属于依据同种布艺工艺的合理补全：

- 左右侧面（用于校准头部厚度、嘴部翻边、手臂与裤子的前后关系）
- 背面（背带在背后的走法、裤子后片结构）
- 眼部特写（眼眶抽褶的数量、密度与走向）
- 顶部连接结构（皮绳打结方式、金属环与标签的连接细节）

补齐自有实拍照片后，应优先修正这些部分，并同步更新 `scripts/blender/build_frog.py` 中的控制点参数。
